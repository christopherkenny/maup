# Package index

## Download data

Download maps and plans from the Harvard Dataverse.

- [`maup_tract_map()`](http://christophertkenny.com/maup/reference/maup_tract_map.md)
  : Download MAUP county-level maps
- [`maup_tract_plans()`](http://christophertkenny.com/maup/reference/maup_tract_plans.md)
  : Download MAUP county-level plans

## Cache management

Inspect and clear the local download cache.

- [`maup_cache_path()`](http://christophertkenny.com/maup/reference/maup_cache_path.md)
  :

  Return the path to the `maup` cache

- [`maup_cache_size()`](http://christophertkenny.com/maup/reference/maup_cache_size.md)
  :

  Report the size of the `maup` cache

- [`maup_cache_clear()`](http://christophertkenny.com/maup/reference/maup_cache_clear.md)
  :

  Clear the `maup` cache
